## ✦ About

**Special New** is a fan-made web application created for Whiteout Survival players.

The project brings frequently used game tools into one clean, responsive interface, with a focus on making calculations **fast, readable, and practical** on both desktop and mobile.

> Built as a personal project for players who want useful tools without unnecessary complexity.

## 🚀 Getting Started

### Requirements

Make sure you have:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

```bash
git clone <YOUR_REPOSITORY_URL>
cd <PROJECT_DIRECTORY>
npm install
```

### Development

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### Production Build

```bash
npm run build
npm run start
```
